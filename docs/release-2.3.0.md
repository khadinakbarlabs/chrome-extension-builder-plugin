# Chrome Extension Builder 2.3.0

This upgrade makes ongoing extension work easier to resume, review and improve. The shared capability corpus is delivered through Claude, Codex/OpenAI and Cursor native editions.

- Project context records explicitly supplied goals, audience, confirmed decisions, provisional assumptions, evidence and a next action. Focused fixes route directly to the relevant specialist pass.
- Four focused skills add Context, Feedback, Report and Follow-up to the existing lifecycle. Twelve specialist roles retain ownership and evidence gates.
- Optional local helpers record scoped decisions, sanitized feedback and meaningful outcomes, then generate JSON and Markdown reports. Human sessions, scheduled runs and retries remain distinct. No feedback upload or cross-user telemetry is added.
- Optional Studio provides seven project review views with safe report interchange, labelled evidence, stale status after changes, candidate comparison and review before application. Concepts and declared checklists remain distinct from observed browser results.
- Follow-up specifications support host-backed continuation, feedback triage and compatibility review. They require a concrete user request, capability check and observed activation. A local specification is not an active scheduler; no schedule starts on installation.

The package remains skills-only: no MCP, hooks, account service, credential intake or automatic startup. Local persistence is optional; conversation remains useful without local tools. The public compatibility artwork is independent and does not imply provider endorsement.

## Verification boundary

Source tests, extracted native package smoke checks and Studio interaction checks are recorded in the versioned release evidence. These do not prove all native host discovery/semantic behavior, a deployed backend, Chrome Web Store approval, policy certification or a measured tenfold improvement. Directory states are recorded only after readback from each provider.
