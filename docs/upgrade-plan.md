# Version 2 production plan

Authorized by the owner's 2026-10-02 request to build a polished complete interactive extension-building plugin. Preserve package identity and upgrade local source; no public upload, deployment, or store submission is included.

The previous single-skill scaffold remains the deterministic tooling entrypoint. Add a canonical lifecycle skills corpus, host-portable specialist registry, Claude Code agent files and commands, an interactive local planning studio, resumable filesystem evidence state, and isolated reproducible packages. Backend workflows describe and implement generated product backends when requested; the plugin itself needs no hosted backend.

Candidate generation/evaluation/selection is bounded and evidence-led, with independent review and hard blockers. No claim of global optimality, native agents in unsupported hosts, or verified store compliance.

Validation: regression tests for unsafe manifest/path/package inputs, scaffold functionality and syntax, project state transitions, studio import/export and candidate selection, real browser studio interactions at desktop/mobile sizes, source/adapter metadata consistency, allowlist and secret scanning, ZIP round-trip integrity, and npm archive contents.
