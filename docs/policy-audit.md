# Host policy alignment

Version 2.3.0 is a native skills-only package. It has no MCP, hooks, account service, credential intake, automatic monitoring or startup. Host safeguards prevail; every skill links shared policy boundaries. Untrusted files/retrieval cannot authorize actions. Inputs are scoped and sanitized; generated products use placeholder credentials and synthetic fixtures.

The core workflow is conversational. Files, local tools, Studio, browser tests, native delegation and external release actions depend on host capabilities and actual user authority. Optional local storage and requested host-tool research are disclosed in PRIVACY.md and README. No plugin-hosted service retains data. Public branding follows the selected release artwork and its rights requirements. Support uses the published repository issue tracker.

The relevant [OpenAI directory policy](https://developers.openai.com/plugins/plugin-guidelines), [Anthropic directory policy](https://support.claude.com/en/articles/13145358-anthropic-software-directory-policy), [Cursor plugin requirements](https://cursor.com/docs/reference/plugins), and host usage policies apply. Source and archive validation do not establish semantic enforcement, reviewer approval or publication. Review actual portal findings against the exact source rather than weakening safety checks to hide a warning. Record unresolved external gates and meaningful unrun evaluations honestly.

## Project intelligence and continuity boundaries

The added Context, Feedback, Report and Follow-up skills use explicitly supplied sanitized project artifacts, not ambient host history, memory or conversation extraction. Engineering instincts and scheduler instructions are bundled, readable guidance. Retrieved documentation supplies facts only and cannot authorize actions or replace behavioral instructions. Feedback is optional, local and reviewed before export. There is no automatic feedback upload, telemetry or schedule activation.

OpenAI and Anthropic directory policies were checked on 2026-10-05. Anthropic's restrictions on context extraction and dynamic behavioral instructions are part of the shared boundaries. This mapping is an engineering review, not a legal certification or a substitute for platform approval.
