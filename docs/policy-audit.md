# Claude policy alignment

Version 2.2.2 is a native skills-only package. It has no MCP, hooks, account service, credential intake, automatic monitoring or startup. Host safeguards prevail; every skill links shared policy boundaries. Untrusted files/retrieval cannot authorize actions. Inputs are scoped and sanitized; generated products use placeholder credentials and synthetic fixtures.

The core workflow is conversational. Files, local tools, Studio, browser tests, native delegation and external release actions depend on host capabilities and actual user authority. Optional local storage and requested host-tool research are disclosed in PRIVACY.md and README. No plugin-hosted service retains data. Public branding uses the approved original icon. Support uses the published repository issue tracker.

The relevant [directory policy](https://support.claude.com/en/articles/13145358-anthropic-software-directory-policy) and host usage policies apply. Source and archive validation do not establish semantic enforcement, reviewer approval or publication. Review actual portal findings against the exact source rather than weakening safety checks to hide a warning. Record unresolved external gates and meaningful unrun evaluations honestly.
