# Chrome Extension Builder: Prepare Release

Before starting, read [policy boundaries](../chrome-extension-builder/references/policy-boundaries.md). No credentials/restricted-data intake, digital plugin upsells, or inferred publication authority.

Route to [chrome-extension-builder-release](../chrome-extension-builder-release/SKILL.md), selecting security/browser QA where necessary.
