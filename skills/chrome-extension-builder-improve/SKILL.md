# Chrome Extension Builder: Improve

Before starting, read [policy boundaries](../chrome-extension-builder/references/policy-boundaries.md). Preserve host safeguards, scoped sanitized inputs, and user choices.

Route to [chrome-extension-builder-evolution](../chrome-extension-builder-evolution/SKILL.md) and the relevant UX/architecture/performance skills. Define baseline, acceptance, at most three candidates per round and three rounds by default, canonical rubric, and stop condition. Reject hard safety/authorization/privacy failures before scoring.

Check explicit environment access before local implementation or measurement. Chat comparisons can produce concrete reviewable specifications; unmeasured scores and unrun host evaluation remain labeled. Exit with selected rationale, useful artifact or authorized implementation, regression status, and remaining gates. No indefinite optimization loop or guarantee of global optimality.

Use actual project pain, incumbent evidence, and [feedback](../chrome-extension-builder-feedback/SKILL.md). Freeze acceptance/rubric and measure affected journeys; report demonstrated versus provisional benefit. Preserve established design unless evidence/user intent warrants change.
