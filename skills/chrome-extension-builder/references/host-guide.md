# OpenAI host integration

Use OpenAI skill discovery and each skill's `agents/openai.yaml` display and default-prompt metadata. Where supported, invoke the exact `$chrome-extension-builder-*` skill identifier. Read the 12 specialist role contracts from `team.json` and the main skill's references. Use the host's actual delegation tools with explicit file ownership only when available and authorized; otherwise execute distinct sequential passes and report their independence limit.

Do not assume root native agents, slash commands, or provider-specific variable substitution. Resolve bundled helper paths from the installed skill location only in an explicitly available local environment. Chat-only hosts still produce useful design/code/test artifacts without pretending to execute local tools.

Host safeguards and the shared [policy boundaries](policy-boundaries.md) govern all actions. Native metadata is presentation and routing, not permission to bypass host rules or evidence of a completed run.
